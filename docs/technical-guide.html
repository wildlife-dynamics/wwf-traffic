Technical Guide

A deeper look at how the WWF Traffic Workflow is built: the multi-file CSV merge pipeline, GVL spatial filtering, map and chart methodology, and metric calculations.

Download the full Technical Guide (PDF)

Unlike the EarthRanger-connected workflows in this fleet, WWF Traffic has no live data source — all input data is supplied as CSV uploads, and the only network dependency is a one-time Dropbox download of the GVL boundary file. This guide was written directly against the current spec.yaml.
